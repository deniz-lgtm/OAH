# Oakland Affordable Homes

Static landing page for Oakland Affordable Homes, LLC.

## Files
- `index.html` — landing page
- `styles.css` — styling
- `logo.png` — company logo (add this file before deploying)

## Deploying
This is a static site. Upload all files to any static host (GitHub Pages, Netlify, Vercel, S3, etc.).

**Important:** Save the company logo as `logo.png` in this directory before deploying.
